TRREE GAMER QUIZ - PASSO A PASSO
================================

IMPORTANTE
Este jogo usa Node.js, nao usa Python.

1) BAIXAR
Extraia o ZIP e abra a pasta TRREE-GAMER-QUIZ-10.

2) ABRIR NO VS CODE
No VS Code: Arquivo -> Abrir Pasta -> escolha TRREE-GAMER-QUIZ-10.

3) INICIAR O SERVIDOR
No Explorador de Arquivos do Windows, entre na pasta do jogo e dê dois cliques em:
INICIAR_JOGO.bat

Na primeira vez, ele instala automaticamente os componentes com npm.
Deixe a janela preta aberta durante a apresentação.

4) TELA DO PROFESSOR
No computador do professor abra:
http://localhost:3000/host

Clique em CRIAR SALA.
O sistema gera um PIN de 6 números e um QR Code automaticamente.

5) CELULARES DOS ALUNOS
Professor e celulares precisam estar na mesma rede Wi-Fi.
Mostre o QR Code na tela do professor.
Cada aluno aponta a câmera do celular e entra na sala.

6) SE O CELULAR NAO CONSEGUIR ABRIR O QR
O Windows pode perguntar se o Node.js deve ter acesso à rede.
Permita o acesso para redes privadas.
Se aparecer bloqueio do Firewall do Windows, permita o Node.js na rede privada.

7) FLUXO DA PARTIDA
Criar sala -> alunos entram -> INICIAR QUIZ -> 10 perguntas -> ranking -> pódio 1º/2º/3º.

8) AVATARES
Mouse, teclado, monitor, CPU, placa-mãe, internet, roteador, notebook, celular, gamepad, headset e webcam.
Cada avatar tem carinha/boca divertida e seleção no celular.

9) PERGUNTAS
São 10 perguntas adaptadas dos temas públicos do W3Schools em HTML, CSS e JavaScript.
Fontes para estudo:
https://www.w3schools.com/quiztest/quiztest.asp?qtest=HTML
https://www.w3schools.com/quiztest/quiztest.asp?qtest=css
https://www.w3schools.com/quiztest/quiztest.asp?qtest=javascript
https://www.w3schools.com/quiztest/quiztest.asp?qtest=IHTMLCSS
https://www.w3schools.com/html/html_quiz.asp
https://www.w3schools.com/htmlcss/htmlcss_quiz.asp

10) PARA APRESENTAR NA SALA
- Abra o jogo no computador do professor.
- Conecte o PC e os celulares na mesma Wi-Fi.
- Crie a sala.
- Projete a tela do professor.
- Mostre o QR Code.
- Os colegas entram pelo celular.
- Inicie o quiz.
