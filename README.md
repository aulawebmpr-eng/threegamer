# TRREE GAMER QUIZ 10

Jogo de perguntas multiplayer, estilo Kahoot, para apresentação de Programador Web.

- PIN de 6 dígitos
- QR Code automático
- Vários jogadores no mesmo grupo
- 10 perguntas de HTML/CSS/JavaScript inspiradas nos conteúdos públicos do W3Schools
- Avatares de tecnologia com carinhas divertidas
- Pontos por acerto + velocidade
- Ranking ao vivo
- Sons por Web Audio
- Tela do professor otimizada para projetor
- Pódio com 1º, 2º e 3º
- Logo original TRREE GAMER

## Requisitos
Node.js 18+.

## Rodar
Duplo clique em `INICIAR_JOGO.bat`.
Depois abra `http://localhost:3000/host`.
